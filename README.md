# apps

スマホ向けのゲーム・便利アプリをまとめて公開するリポジトリです。

## 収録アプリ

- [全部入り関数電卓](./scientific-calculator/) — 厳密値・小数・グラフ・微積分・行列・統計・単位換算まで端末内で使えるPWA
- [POKER EQUITY](./poker-equity/) — テキサスホールデムのハンド・ボード・人数から勝率、引き分け、役分布、アウト後の勝率を計算
- [今期ドラマカレンダー](./tv-drama-calendar/) — 2026年夏ドラマを曜日・時間・テレビ局から探し、出演者・概要・今週の話数を確認
- [ONE NEWS](./ai-news/) — RSS・公式フィードを自動取得し、重複記事を1つに統合して背景・重要性・確認ポイントまで整理するニュースアプリ
- [かんたん家計簿](./money-manager/) — 収入・支出・予算を月ごとに管理し、データを端末内に保存するアプリ
- [1→25 TAP](./number-tap-25/) — 1から25まで順番にタップしてタイムを競うゲーム
- [ノリ打ち精算](./noriuchi-calculator/) — 投資・回収・配分率から精算額を計算するアプリ
- [LOGIC MINES](./minesweeper/) — 特殊ルール、ステージ、デイリーを搭載した思考型マインスイーパー
- [日本AV女優名鑑](./av-actress-directory/) — 公開プロフィールを複数条件で検索できる18歳以上向け人物データベース
- [よい時計（iOS）](./ios/yoitokei/) — SwiftUI製の時計・アラーム・タイマー・ストップウォッチ

## 公開構成

WebアプリはGitHub Pagesで `main` ブランチの `/ (root)` を公開すると、トップページから各アプリを起動できます。

iOSアプリは各フォルダ内のREADMEに従い、Mac上のXcodeでビルドします。
