# うまログAI

東京・中山・京都の平地競走を対象に、近走・適性・枠順・騎手など10項目を100点満点で整理するスマホ向けPWAです。初版のJRA HTML取込は障害競走に対応していません。

## 実装済み

- 前日版と当日最終版を別スナップショットとしてIndexedDBへ保存（各版の締切より前だけ）
- 採点・順位・予想時オッズは最初の保存後に固定し、買い目予算は締切前の追記履歴として変更可能
- 10カテゴリの点数・充足度・評価理由・直近5走を表示
- `◎ ○ ▲ △ ☆ 消`、予想順位、自信度を算出
- オッズは参考表示のみ（採点・順位・買い目・予算配分から完全分離）
- 単勝、複勝、馬連、ワイド、馬単、三連複、三連単の買い目と100円単位の予算配分
- 確定結果との順位差、◎の的中、Top3一致、買い目的中、払戻・回収率を照合
- 発走前に保存できた予想だけを対象に、東京・中山・京都、芝・ダート、距離帯、券種ごとの累積成績を表示
- 発走前スナップショット付きの過去1年を開催日単位で60%・20%・20%に時系列分割し、検証・最終確認で悪化しない場合だけカテゴリ配点を更新
- Windowsで保存したJRA公式の詳細出馬表・結果HTMLを端末内だけで解析し、レース単位で追加・更新
- 端末内JSONインポート、オフライン用PWAキャッシュ

## データについて

公開リポジトリには実在のJRAデータを同梱せず、初期表示にも架空レースを出しません。利用者自身が保存した公式HTMLから必要項目だけを正規化し、ブラウザのIndexedDBへ保存します。HTML、画像、スクリプトは保存・送信しません。

[JRAの利用条件](https://www.jra.go.jp/use/)と[JRA-VANの利用規約](https://jra-van.jp/info/rule.html)を確認しましたが、この公開Webアプリで利用できる無料公開APIや再配布許諾は確認できませんでした。本機能は利用者本人の私的利用を前提とし、許諾を確認できない自動取得・公開JSONへの転載を実装しません。保存HTMLと取込データを共有・転載しないでください。

### 完全無料の端末内取込

1. WindowsのChromeまたはEdgeで、JRA公式の対象レース「詳細出馬表」を開く
2. `Ctrl+S` を押し、「Webページ、HTMLのみ」で保存する
3. うまログAIの「設定」で「前日版」「当日最終版」「参考表示」のいずれかを明示してから、保存ファイルを選ぶ
4. レース後は「参考表示・結果取込」を選び、公式の「レース結果」も同じ方法で取り込む

複数HTMLをまとめて選択できます。前日版はレース前日、当日最終版はレース当日の発走2分前までだけ確定できます。古い内容を誤って確定しないよう、版の確定には保存後30分以内の出馬表HTMLだけを受け付けます。版を確定した最初の予想は後の再取込でも変更しません。締切後の出馬表は「参考表示」で端末内保存できますが、新しい予想・成績は作りません。

JRAの詳細出馬表から取得できる近走は4走です。5走目、追い切り、一般騎手成績など未取得の項目は推測せず中立値とし、データ充足度と自信度を下げます。脚質と想定ペースだけは、近走の通過順位から端末内で機械的に推定します。オッズは表示だけに使い、採点・順位・買い目配分には使いません。

同着を含む結果は、現行スキーマで正確な順位差を表現できないため安全に取込を停止します。

### その他の接続口

1. 利用者が正当に取得した正規化JSONを「設定」から端末内へ読み込む
2. 再配布許諾のあるプロバイダーを `UMA_LOG_DATA_URL` に接続する
3. 将来、法人向けライセンス済みバックエンドへ接続する

自動更新ワークフローは、リポジトリ変数 `UMA_LOG_DATA_URL` と `UMA_LOG_DATA_LICENSE_CONFIRMED=true` の両方が設定された場合だけ取得します。受信JSONには `source.redistributable: true` に加え、各特徴量がスナップショット時点で固定済みであるという提供元の保証 `source.asOfFieldsGuaranteed: true` が必要です。

## 開発・検証

```bash
npm ci --prefix uma-log-ai --ignore-scripts
node --check uma-log-ai/engine.js
node --check uma-log-ai/demo-data.js
node --check uma-log-ai/jra-importer.js
node --check uma-log-ai/app.js
node --check uma-log-ai/learning-worker.js
node --test uma-log-ai/tests/*.test.mjs
node uma-log-ai/scripts/validate-race-data.mjs
```

静的ファイルのためビルドは不要です。リポジトリルートをWebサーバーで配信し、`/uma-log-ai/` を開いて確認します。
