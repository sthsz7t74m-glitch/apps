# 漢字の間｜準1級トレーニング

漢検準1級を目指す自主学習用のクイズアプリ。公式アプリや過去問ではありません。

- 読み80問、四字熟語の意味40問
- 5・10・20問のランダム出題（収録数が上限）
- 読みは4択または入力、四字熟語は4択
- 解説、間違えた問題の復習、端末内の学習記録

## 公開先

https://sthsz7t74m-glitch.github.io/apps/kanji-jun1/

ビルド不要。`index.html` と隣接する3ファイルをそのまま配信します。
`app.js` はESモジュールのため、ローカル確認時もHTTPサーバーで配信してください。

## 編集

- `questions.js`: 問題・正答・許容読み・選択肢・意味・例文
- `app.js`: 出題・採点・復習・記録
- `style.css`: 画面・スマートフォン向けレイアウト

学習記録はブラウザのlocalStorageに保存されます。端末間や別ドメイン間で同期しません。

## テスト

このフォルダで `npm test`。依存パッケージのインストールは不要です。

ホームとクイズは表示領域に合わせた1画面構成です。ホームの教材説明はダイアログで開きます。
