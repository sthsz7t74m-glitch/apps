# 競馬予想

JRA全10競馬場とNAR地方競馬を切り替え、勝率・複勝圏率・ワイド同時圏内率と実オッズを比較する白基調のPWAです。JRAの初期データとして、2026年8月9日の札幌・新潟・中京36Rを実在の馬名・出馬情報・当日モデル勝率・結果で表示します。地方競馬はNAR公式の日次ZIPを利用者のブラウザ内だけで展開・保存し、公開リポジトリへレースデータを収録しません。

v2.4.0では中央／地方の切替、NAR公式レース情報・オッズ情報ZIPの端末内取込、地方競馬用の時系列監査済み参考モデルを追加しました。単勝・複勝・ワイドから1レース最大1点を比較しますが、地方競馬は前向き収益検証が未完了のため、すべて参考表示・実購入0円です。

## 地方競馬

- NAR全15場を表示対象とし、サラブレッド14場を参考予想の対象にする
- 帯広のばんえい競馬は出走・オッズ・結果を表示するが、サラブレッド用モデルから分離する
- NAR公式の日次レース情報ZIPと日次オッズ情報ZIPを、ブラウザ内だけで展開する
- 同じ開催日のレース、馬、単勝・複勝・ワイド、結果、払戻をIndexedDBへ端末内保存する
- ZIP名の公式生成時刻から取得時点を判定し、発走1〜10分前だけを発走前参考として集計する
- 判定時刻外と結果後の取込は表示のみとし、予想成績へ混ぜない
- 公式CSV、馬名、オッズ、結果はGitHubや外部サーバーへ送信・同梱しない

### NAR参考モデルの監査

2026年3月1日〜8月8日のサラブレッド6,065Rを対象に、3月→4月の調整と、5月・6月・7月・8月1〜8日のローリング前向き評価を行いました。市場単独と、馬・騎手・コース・距離など22特徴の残差を加える候補を勝者対数損失で比較した結果、残差モデルは市場単独を上回らなかったため不採用とし、正規化した単勝最終オッズの市場基準を採用しています。複勝・ワイドの着順温度は0.8です。

最終オッズには約定可能な取得時刻の保証がないため、この監査は利益検証ではありません。モデル設定と監査値だけを `data/nar-model.json` に収録し、元のNARレースデータは収録しません。再監査用の `scripts/train-nar-model.py` は利用者が正当に取得・展開した公式CSVをローカル入力として使い、外部サイトを巡回しません。

## 2026年8月9日 実データ

- 札幌・新潟・中京の全36R、495頭を収録
- 平地35Rは当日に算出したモデル順位と勝率を再現
- 20Rは発走前取得として参考成績へ集計
- 20Rは保存済み単勝・複勝レンジオッズを収録
- 15Rは発走後取得と明示し、前向き成績・学習・利益検証から除外
- 中京9Rの障害戦は出馬情報と結果のみ表示し、モデル対象外
- 上位着順はJRA公式結果と照合済み

収録データは取得ページのHTML・記事・画像を転載せず、レースの事実と本アプリが算出した予測値だけに正規化しています。`scripts/build-real-archive.py` は既に取得済みの入力ファイルを変換するだけで、外部サイトを巡回しません。

## v5の考え方

近走、血統、馬場、コース、距離、枠、左右回り、脚質構成、騎手、馬体重、休養間隔、スタート、ラスト4F、当日の状態を能力特徴量として使います。市場オッズを土台にして、能力特徴量が説明する市場との差だけを条件付きロジットで加えます。

市場確率を `q`、能力特徴量を `x` とすると、最終勝率は次式です。

```text
q_i = (1 / 単勝オッズ_i) / Σ(1 / 単勝オッズ_j)
p_win_i = softmax(α log q_i + βᵀx_i)
```

- 旧v4の `q × (p/q)^0.8` は、市場を既に含む最終勝率へ市場縮小を二重適用していたため廃止
- 2018〜2021年を「直前年で調整→翌年を未使用評価」の4分割、計10,901Rで比較
- 採用は勝者対数損失だけで決め、市場単独1.96440に対しv5は1.96073。回収率は式選択に不使用
- 複勝・ワイドは最終勝率からPlackett–Luce着順確率を厳密計算し、温度0.8が4分割すべてで未校正値より改善
- 発走1〜10分前に取得し、取得後2分以内に計算した時刻付き実オッズを使用
- 複勝・ワイドのレンジは下限を採用し、全券種のオッズをさらに10%下げる
- 期待値が+5%以上だけ仮想100円で前向き検証。1レース最大1点
- 利益ゲート通過までは実購入0円
- 解禁後も8分の1Kelly、1R資金0.25%、1日1%を上限とする

現在の公開ステータスは `data/forward-status.json` の `LOCKED` です。利益や的中を保証するものではありません。

## データの扱い

公開リポジトリには元ページの保存HTMLや記事本文を同梱せず、JRAの8月9日分だけを正規化済みのレース事実と独自予測として `data/races.json` に収録します。別日を利用者が追加する場合は、JRA公式ページをHTML保存し、設定画面から読み込むと、ブラウザ内だけで解析してIndexedDBへ保存します。HTML、画像、スクリプトを外部送信しません。

地方競馬はNARの利用条件を踏まえ、公式CSVやそこから復元できるレース単位データを公開配布しません。利用者自身がNAR公式から保存した日次ZIPを `nar-importer.js` がブラウザ内で解析し、端末内のIndexedDBへ保存します。アプリの通信先は同一オリジンに限定しています。

HTML取込だけの場合、100点評価を確率へ換算した「参考勝率」を表示します。これはv5校正外なので購入判定には使いません。前向き仮想判定には、発走前固定済みの全出走馬分 `v5WinProbability`（互換入力は `v3WinProbability`）と、券種別実オッズを含む正規化JSONが必要です。

```json
{
  "probabilityModel": {
    "version": "5.0.0-stable",
    "frozenBeforePost": true,
    "output": "final-win-probability"
  },
  "oddsSnapshotAt": "2026-08-15T09:55:00+09:00",
  "horses": [
    {
      "number": 1,
      "odds": 4.2,
      "placeOdds": { "lower": 1.8, "upper": 2.2 },
      "v5WinProbability": 0.28
    }
  ],
  "wideOdds": [
    { "numbers": [1, 5], "lower": 4.6, "upper": 5.2 }
  ]
}
```

全馬の最終勝率合計が1でない、取得時刻が発走1〜10分前でない、オッズ取得から計算まで2分を超える、取消後の頭数が揃っていない場合は安全側へ停止します。複勝・ワイドの実オッズがなければ、その券種は必要最低オッズの表示だけです。

8月9日の公開アーカイブはv2当日モデルを保存したものです。v5の学習・係数選択に8月9日の結果は使っていませんが、v5式自体を後から適用したため「参考候補」として表示し、正式購入・前向き仮想収支には含めません。実購入は0円です。

## 端末内HTML取込

1. WindowsのChromeまたはEdgeで、JRA公式の対象レース「詳細出馬表」を開く
2. `Ctrl+S` で「Webページ、HTMLのみ」として保存する
3. アプリの「設定」で前日版・当日最終版・参考表示を選び、保存HTMLを読み込む
4. レース後はJRA公式の「レース結果」を同様に保存し、参考表示・結果取込で精算する

前日版と当日版の最初の予想は発走前スナップショットとして固定され、結果後の再計算を過去成績へ混ぜません。同着、返還、取消は公式払戻データが揃わない場合に安全停止します。

## 端末内NAR ZIP取込

1. NAR公式の[日次レース情報](https://www.keiba.go.jp/KeibaWeb/DataDownload/RaceDataDownload?type=daily)と[日次オッズ情報](https://www.keiba.go.jp/KeibaWeb/DataDownload/OddsDataDownload?type=daily)を開く
2. 同じ開催日のZIPを各ページから1つずつ保存する
3. アプリで「地方競馬」へ切り替え、「設定」から2ファイルをまとめて選ぶ
4. 締切前の参考予想を更新する場合は、最新のオッズ情報ZIPをレース情報ZIPと一緒に再取込する

公式CSVはブラウザ外へ送信しません。保存・取込データは私的利用に限り、共有・転載しないでください。

## 対応特徴量

- 実装済み：近走、芝・ダート、距離、競馬場、左右回り、馬場状態、枠、脚質構成、騎手、斤量、馬体重、前走間隔、血統、調教師、追い切り、スタート、ラスト4F
- 任意入力：気温、風向・風速、筋肉評価、気温適性、風適性
- データが無い項目は推測せず中立値とし、充足度を下げる
