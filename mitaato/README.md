# ミタアト 記事デスク

note用の記事下書きを、領域ごとにワンタップでコピーし、投稿状況まで管理する静的PWAです。

## できること

- タイトル、価格・ネタバレ範囲、無料部分、有料部分、タグ、サムネ文言、画像生成プロンプトを個別コピー
- 本文一括コピー後にnote新規投稿画面を開く
- 未投稿、確認済み、投稿済み、保留の管理
- 投稿予定日時の保存
- 作品名、カテゴリ、投稿状況、優先度による絞り込み
- ChatGPTの分割出力またはJSONを一括取り込み
- 端末内で本文を修正し、元データを壊さず保存
- GitHub Actionsによる最新記事の自動調査・生成

投稿状況、投稿予定、端末内編集はブラウザのlocalStorageへ保存されます。生成された記事データは `data/articles.json` から読み込みます。

## 自動生成の設定

GitHubリポジトリの Settings → Secrets and variables → Actions で、次を設定します。

### 必須Secret

- `OPENAI_API_KEY`

### 任意Variables

- `MITAATO_OPENAI_MODEL`：既定値 `gpt-5.6`
- `MITAATO_ARTICLE_LIMIT`：1回に生成する記事数。既定値 `3`、最大 `6`

設定後、毎日04:45（日本時間）に次の処理を行います。

1. 最新72時間のアニメ、漫画、ドラマ、映画、都市伝説をWeb検索
2. 公式一次情報を優先して候補を採点
3. 直近記事との重複を除外
4. ミタアト形式の記事、タグ、サムネ文言、サムネ生成プロンプトを作成
5. `data/articles.json` へ未投稿の下書きとして保存
6. GitHub Pagesへ自動反映

Actionsの `Generate MITAATO article drafts` から手動実行もできます。カテゴリと生成数を指定できます。

## 注意

- APIキーはGitHub Secretだけに保存し、ブラウザへ埋め込みません。
- ChatGPTの契約とOpenAI APIの利用料金は別管理です。
- 自動生成記事は投稿前に一次情報、固有名詞、話数、公開日、ネタバレ範囲を確認してください。
- noteへの完全自動投稿は行いません。最後の投稿操作は本人が確認します。
