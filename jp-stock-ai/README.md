# 日本株AI予測 v0.4.0

GitHub Pages対応の5取引日後株価予測アプリ。トップページ: `/jp-stock-ai/`。

## 仕組み
- GitHub Actions `update-jp-stock-ai.yml` が平日18:20 JST（UTC 09:20）にデータを再取得・学習し、予測JSONをコミット。実際の実行開始は遅延する場合があります。
- `predict.py` はYahoo Finance経由で東証銘柄の自動調整後日足7年分を取得し、特徴量（移動平均・騰落率・RSI・出来高・ボラティリティなど）を計算。
- 5営業日後騰落率の回帰と上昇確率の分類にHistGradientBoostingモデルを採用。
- 時系列順80%学習／20%検証、5取引日分のギャップを入れ、一定期間保持した検証結果を表示します。
- 比較指標は変化なし予測のMAE、および常に多数派方向を当てるベースラインです（後者は方向の参考値）。過去の検証成績は将来の成績を保証しません。
- 上昇確率は校正されていないモデル出力であり、信頼できる発生確率として扱わないでください。
- 取引所の営業日を暦上で正確に計算するわけではなく、**5取引日先**を対象とします。
- 直近の公開済みJSONが無い／取得が失敗した場合は予測を表示せず、架空データで埋めません。

## 5取引日前の予測を答え合わせ
直近の終値を対象に、5取引日前の特徴量とその時点までに確定していた教師ラベルだけでモデルを再学習します。予測価格と実績価格、価格誤差、上昇・下落の判定を表示します。これは後からの再現テストであり、当日保存された実予測の監査記録ではありません。調整後株価は過去に遡って修正される場合があります。

## 買い候補・売り候補ランキング（v0.3.0）
- 東証主要50銘柄を対象（構成銘柄は固定。市場全体の全銘柄ではありません）。
- 予測騰落率の降順で「買い候補」、昇順で「売り候補」を最大20件表示します。**実際の売買を推奨するものではありません。**
- 検証期間の平均絶対誤差が「5取引日後も株価変化なし」の予測を下回り、方向的中率が多数派方向予測を上回った場合のみ「基準通過」と表示します。ただし同じ期間をランキング対象ごとに再利用する検証であり、取引戦略の収益性は未検証です。
- データの直近基準日が7暦日より前ならランキングを非表示にします。生成日時・銘柄の基準日も確認してください。
- 銘柄を押すと個別の株価予測・検証へ移動します。
- ランキングはその時点のモデル推計だけに基づき、手数料・税・流動性・売買スプレッド・決算イベント等を考慮しません。

## 予測と実際の値動きの重ね合わせ（v0.4.0）
- 5取引日前の履歴再現予測の起点・終点と、実際の直近5取引日の調整後終値6点を同じSVG座標上に描きます。
- 青の実線は日々の実際の終値、オレンジの点線は予測開始価格と**5取引日後の予測終値を結ぶ補助線**です。AIは日次の中間価格を予測していません。
- 予測値・誤差率・方向的中とグラフを銘柄単位で連動表示。
- 取得済みのJSONにある `history` と `one_week_ago_check` を利用するため、該当する6取引日の履歴が揃えば表示可能です。データ不足時に架空の途中価格を作りません。
- 過去の再現テストであり、当時の実際の予測配信記録ではありません。調整後の過去株価は分割等で遡及変更されることがあります。

## 初回セットアップ
GitHub Actionsタブから `Update Japanese stock AI forecasts` を **Run workflow** で手動実行してください。Actionsの書き込み権限（Settings > Actions > General > Workflow permissions）が必要な場合があります。

ローカル実行:
```sh
python -m pip install -r jp-stock-ai/requirements.txt
python jp-stock-ai/predict.py
python -m http.server 8000
```
`http://localhost:8000/jp-stock-ai/` を開きます。

## 注意
自動売買機能はありません。予測は投資助言ではなく学習・検証用。株価の利用条件や配信遅延に注意してください。
